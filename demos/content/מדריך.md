# מדריך קצר לכתיבה בעברית

SoloMD מזהה מסמך עברי ומציג אותו **מימין לשמאל** — בעורך, בתצוגה המקדימה ובמצב קריאה.

## למה זה חשוב

- הסמן והשוליים עומדים בצד הנכון
- רשימות וציטוטים מיושרים לימין
- מילים באנגלית כמו `Markdown` או React משתלבות בתוך המשפט בלי לשבור אותו

> כתיבה טובה היא חשיבה ברורה שהפכה לגלויה.

קוד נשאר משמאל לימין:

```ts
const greeting = (name: string): string => `שלום, ${name}`;
```
