# Git Pane Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** JetBrains-style git client in SoloMD for the open workspace folder — Commit panel (left), Git Log dock (bottom), diff editor tabs, status-bar branch widget.

**Architecture:** Port git-light's Rust git-CLI layer into `app/src-tauri/src/git_pane/` behind a `GitEngine` trait, exposed as 8 `gitpane_*` Tauri commands. Port git-light's pure TS (wire models, graph layout, diff helpers) into `app/src/lib/git-pane/`. A Pinia store `gitPane` is the only UI ↔ backend path; Vue components are rewritten in SoloMD style (no Tailwind / reka-ui).

**Tech Stack:** Rust (tokio::process, notify 8 + notify-debouncer-mini 0.7, tracing), Tauri 2, Vue 3.5 + Pinia 3, highlight.js 11, `@tanstack/vue-virtual`, `node:test` (TS run natively by Node 22).

**Spec:** `docs/superpowers/specs/2026-10-20-git-pane-design.md`

## Global Constraints

- Desktop only: every Rust item `#[cfg(not(any(target_os = "android", target_os = "ios")))]`; every UI entry point gated by `hasGitBackend() && settings.enableGitPane` and `isTauri()`.
- Engine: system `git` CLI only, argv arrays, never a shell string. User refs/paths go after `--`.
- Tauri command prefix `gitpane_`; event name `gitpane:changed`.
- Ported files keep the git-light MIT header (Task 1 Step 1 text) as the first lines.
- git-light source pinned at commit `56f2ce784231750cd576e4722df2355eb92a4149`.
- New TS modules under `app/src/lib/git-pane/` use **explicit `.ts` import extensions** (Node's type stripping needs them; `allowImportingTsExtensions` is on). No TS `enum`, no parameter properties.
- Tests: Rust `cargo test --manifest-path app/src-tauri/Cargo.toml git_pane`; TS `node --test <file>` from `app/`.
- No comments in new code except MIT headers and genuinely non-obvious "why" (user CLAUDE.md).
- No magic numbers — named constants.
- Logical CSS only (`inset-inline-*`, `padding-inline`, `margin-inline`); commit text `dir="auto"`; SVG graph + hashes `dir="ltr"`.
- Strings in `app/src/i18n/en.ts` under `git`; other locales fall back to English (no `he`/`ar` locale files exist in this repo).
- Shortcuts: `Mod+0` commit panel, `Mod+9` log dock, `Mod+Enter` commit (message box only), `Mod+Shift+U` push, `Mod+Alt+U` update project.
- Version bump target: **4.23.0** (`app/package.json`, `app/src-tauri/tauri.conf.json`, `app/src-tauri/Cargo.toml`).
- Commit on `main` (user choice), one commit per task, trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

| --- | --- | --- |

- [ ] **Step 3: Implement `env.rs`**

```rust
use std::path::{Path, PathBuf};
use std::sync::OnceLock;

const FORWARDED_VARS: [&str; 4] = ["PATH", "SSH_AUTH_SOCK", "GNUPGHOME", "GPG_TTY"];
const XCODE_STUB_PATH: &str = "/usr/bin/git";
const FALLBACK_SHELL: &str = "/bin/zsh";

pub struct GitEnv {
    pub git_path: Option<PathBuf>,
    pub vars: Vec<(String, String)>,
}

static GIT_ENV: OnceLock<GitEnv> = OnceLock::new();

pub fn global() -> &'static GitEnv {
    GIT_ENV.get_or_init(resolve)
}

pub fn git_command() -> tokio::process::Command {
    let env = global();
    let program = env.git_path.clone().unwrap_or_else(|| PathBuf::from("git"));
    let mut cmd = tokio::process::Command::new(program);
    for (key, value) in &env.vars {
        cmd.env(key, value);
    }
    cmd
}

pub fn parse_env_output(raw: &str) -> Vec<(String, String)> {
    FORWARDED_VARS
        .iter()
        .filter_map(|wanted| {
            raw.lines().find_map(|line| {
                let (key, value) = line.split_once('=')?;
                (key == *wanted && !value.is_empty()).then(|| (key.to_string(), value.to_string()))
            })
        })
        .collect()
}

pub fn is_xcode_stub(path: &Path, xcode_select_ok: bool) -> bool {
    path == Path::new(XCODE_STUB_PATH) && !xcode_select_ok
}

pub fn find_on_path(binary: &str, path_var: &str) -> Option<PathBuf> {
    std::env::split_paths(path_var)
        .map(|dir| dir.join(binary))
        .find(|candidate| candidate.is_file())
}

fn login_shell_env() -> Vec<(String, String)> {
    let shell = std::env::var("SHELL").unwrap_or_else(|_| FALLBACK_SHELL.to_string());
    std::process::Command::new(shell)
        .args(["-lc", "env"])
        .stdin(std::process::Stdio::null())
        .output()
        .ok()
        .filter(|out| out.status.success())
        .map(|out| parse_env_output(&String::from_utf8_lossy(&out.stdout)))
        .unwrap_or_default()
}

fn xcode_select_ok() -> bool {
    std::process::Command::new("xcode-select")
        .arg("-p")
        .output()
        .map(|out| out.status.success())
        .unwrap_or(false)
}

fn resolve() -> GitEnv {
    let vars = login_shell_env();
    let path_var = vars
        .iter()
        .find(|(key, _)| key == "PATH")
        .map(|(_, value)| value.clone())
        .or_else(|| std::env::var("PATH").ok())
        .unwrap_or_default();
    let git_path = find_on_path("git", &path_var)
        .filter(|path| !(cfg!(target_os = "macos") && is_xcode_stub(path, xcode_select_ok())));
    GitEnv { git_path, vars }
}
```

```rust
use std::collections::HashMap;
use std::path::{Path, PathBuf};
use std::sync::{Arc, Mutex, OnceLock};

#[derive(Default)]
pub struct RepoLocks {
    by_root: Mutex<HashMap<PathBuf, Arc<tokio::sync::Mutex<()>>>>,
}

static LOCKS: OnceLock<RepoLocks> = OnceLock::new();

impl RepoLocks {
    pub fn global() -> &'static RepoLocks {
        LOCKS.get_or_init(RepoLocks::default)
    }

    pub async fn acquire(&self, path: &Path) -> tokio::sync::OwnedMutexGuard<()> {
        let key = find_repo_root(path).unwrap_or_else(|| path.to_path_buf());
        let mutex = {
            let mut map = self.by_root.lock().unwrap_or_else(|e| e.into_inner());
            map.entry(key).or_default().clone()
        };
        mutex.lock_owned().await
    }
}

pub fn find_repo_root(start: &Path) -> Option<PathBuf> {
    let canonical = start.canonicalize().ok()?;
    canonical
        .ancestors()
        .find(|dir| dir.join(".git").exists())
        .map(Path::to_path_buf)
}
```

```rust
    pub async fn open(folder: &Path) -> Result<Self, GitError> {

        &self.info.path

        git::build_snapshot_with_info(&self.info, opts, &HashSet::new()).await
    }

    async fn log_page(&self, before_sha: &str, limit: usize, all: bool, skip: u32) -> Result<LogPage, GitError> {

        })

        diff::fetch_diff(&self.info.path, req).await

    async fn commit_files(&self, sha: &str) -> Result<Vec<WireWorkingTreeFile>, GitError> {
```

```rust
use std::path::{Path, PathBuf};

const DEBOUNCE_MS: u64 = 300;

pub const CHANGED_EVENT: &str = "gitpane:changed";

#[derive(serde::Serialize, Clone)]
struct ChangedPayload {
    path: String,
}

pub struct RepoWatcher {
    debouncer: Debouncer<notify::RecommendedWatcher>,
    root: PathBuf,
}

impl RepoWatcher {
    pub fn start(app: AppHandle, root: &Path, git_dir: &Path) -> Option<Self> {
        let payload = ChangedPayload { path: root.to_string_lossy().into_owned() };
        let mut debouncer = new_debouncer(Duration::from_millis(DEBOUNCE_MS), move |res: DebounceEventResult| {
            if res.map(|events| !events.is_empty()).unwrap_or(false) {
                let _ = app.emit(CHANGED_EVENT, payload.clone());
            }
        })
        .ok()?;
        for name in WATCHED {
            let target = git_dir.join(name);
            let mode = if target.is_dir() { notify::RecursiveMode::Recursive } else { notify::RecursiveMode::NonRecursive };
            let _ = debouncer.watcher().watch(&target, mode);
        }
        Some(Self { debouncer, root: root.to_path_buf() })
    }

    pub fn root(&self) -> &Path {
        let _ = &self.debouncer;
        &self.root
    }
```

```rust
    operation_id: String,
    kind: String,
    phase: String,
    percent: Option<u32>,
    done: bool,
}

#[tauri::command]
pub async fn gitpane_execute(app: AppHandle, state: State<'_, GitPaneState>, action: ActionValue) -> Result<ActionEnvelope, ()> {
    if !super::kinds::is_allowed(&action.kind) {
        return Ok(ActionEnvelope::err(GitError::unknown(format!("Action \"{}\" is not available.", action.kind))));
    }
    let engine = match current(&state).await {
        Ok(engine) => engine,
        Err(error) => return Ok(ActionEnvelope::err(error)),
    };
    let operation_id = uuid::Uuid::new_v4().to_string();
    let kind = action.kind.clone();
    let op_for_emit = operation_id.clone();
    let emit = move |phase: &str, percent: Option<u32>, done: bool| {
        let _ = app.emit(PROGRESS_EVENT, ProgressPayload { operation_id: op_for_emit.clone(), kind: kind.clone(), phase: phase.to_string(), percent, done });
    };
    let meta = action.meta.unwrap_or(serde_json::Value::Null);
    Ok(engine.execute(&operation_id, &action.kind, action.target.as_deref(), &meta, &emit).await)
}

#[tauri::command]
pub async fn gitpane_cancel(state: State<'_, GitPaneState>) -> Result<(), ()> {
    if let Some(engine) = state.engine.read().await.clone() {
        engine.cancel().await;
    }
    Ok(())
}
```

```ts
import type {
  ActionEnvelope, CommitPageResult, DiffResult, WireRepositorySnapshot, WireWorkingTreeFile,
} from './shared/models.ts'
import type { SerializedGitError } from './shared/errors.ts'
import { GitPaneError } from './service.ts'

type Guard<T> = (value: unknown) => value is T

const isObject = (v: unknown): v is Record<string, unknown> => typeof v === 'object' && v !== null
const isArray = Array.isArray
const isString = (v: unknown): v is string => typeof v === 'string'

export const isFileList: Guard<WireWorkingTreeFile[]> = (v): v is WireWorkingTreeFile[] =>
  isArray(v) && v.every((f) => isObject(f) && isString(f.path) && isString(f.status) && typeof f.staged === 'boolean')

export const isSnapshot: Guard<WireRepositorySnapshot> = (v): v is WireRepositorySnapshot =>
  isObject(v) &&
  isObject(v.repository) && isString(v.repository.currentBranch) &&
  isArray(v.commits) && isArray(v.branches) && isArray(v.tags) &&
  isObject(v.page) && isFileList(v.workingTree)

export const isCommitPage: Guard<CommitPageResult> = (v): v is CommitPageResult =>
  isObject(v) && isArray(v.commits) && isObject(v.page)

export const isDiffResult: Guard<DiffResult> = (v): v is DiffResult =>
  isObject(v) && isString(v.path) && typeof v.binary === 'boolean' && isArray(v.hunks)

export const isEnvelope: Guard<ActionEnvelope> = (v): v is ActionEnvelope =>
  isObject(v) && typeof v.ok === 'boolean' && isString(v.message)

export const isGitErrorPayload: Guard<SerializedGitError> = (v): v is SerializedGitError =>
  isObject(v) && v.__gitError === true && isString(v.code) && isString(v.message)

export function ensure<T>(value: unknown, guard: Guard<T>, what: string): T {
  if (guard(value)) return value
  throw new GitPaneError('protocol', `Unexpected ${what} from the git backend.`)
}

export function toGitPaneError(e: unknown): GitPaneError {
  if (e instanceof GitPaneError) return e
  if (isGitErrorPayload(e)) return new GitPaneError(e.code, e.message, e.detail ?? undefined)
  if (e instanceof Error) return new GitPaneError('unknown', e.message)
  return new GitPaneError('unknown', String(e))
}
```

```ts
import { invoke } from '@tauri-apps/api/core'
import { listen } from '@tauri-apps/api/event'
import type { CommitPageRequest, DiffRequest } from './shared/models.ts'
import type { GitPaneAction, GitPaneService, GitVersionInfo, OpenResult } from './service.ts'
import { ensure, isCommitPage, isDiffResult, isEnvelope, isFileList, isSnapshot, toGitPaneError } from './validate.ts'

const CHANGED_EVENT = 'gitpane:changed'
const SNAPSHOT_COMMIT_LIMIT = 200

async function call<T>(cmd: string, args?: Record<string, unknown>): Promise<T> {
  try {
    return await invoke<T>(cmd, args)
  } catch (e) {
    throw toGitPaneError(e)
  }
}

export function createTauriGitService(): GitPaneService {
  return {
    async version(): Promise<GitVersionInfo | null> {
      try {
        return await call<GitVersionInfo>('gitpane_version')
      } catch {
        return null
      }
    },
    async open(folder: string): Promise<OpenResult> {
      const res = await call<OpenResult>('gitpane_open', { path: folder, options: { commitLimit: SNAPSHOT_COMMIT_LIMIT } })
      if (res.ok) ensure(res.snapshot, isSnapshot, 'snapshot')
      return res
    },
    async snapshot() {
      return ensure(await call('gitpane_snapshot', { options: { commitLimit: SNAPSHOT_COMMIT_LIMIT } }), isSnapshot, 'snapshot')
    },
    async commitPage(request: CommitPageRequest) {
      return ensure(await call('gitpane_commit_page', { request }), isCommitPage, 'commit page')
    },
    async diff(request: DiffRequest) {
      return ensure(await call('gitpane_diff', { request }), isDiffResult, 'diff')
    },
    async commitFiles(sha: string) {
      return ensure(await call('gitpane_commit_files', { request: { sha } }), isFileList, 'commit files')
    },
    async execute(action: GitPaneAction) {
      return ensure(await call('gitpane_execute', { action }), isEnvelope, 'action result')
    },
    async cancel() {
      await call('gitpane_cancel')
    },
    onChanged(listener: () => void) {
      let unlisten: (() => void) | null = null
      let isDisposed = false
      void listen(CHANGED_EVENT, () => listener()).then((off) => {
        if (isDisposed) off()
        else unlisten = off
      })
      return () => {
        isDisposed = true
        unlisten?.()
      }
    },
  }
}
```

```ts
function applyAction(snap: WireRepositorySnapshot, action: GitPaneAction): void {
  const target = action.target
  if (action.kind === 'stage' && target) {
    snap.workingTree = snap.workingTree.map((f) => (f.path === target ? { ...f, staged: true, id: `S:${f.path}` } : f))
  }
  if (action.kind === 'unstage' && target) {
    snap.workingTree = snap.workingTree.map((f) => (f.path === target ? { ...f, staged: false, id: `W:${f.path}` } : f))
  }
  if (action.kind === 'commit' || action.kind === 'commit-and-push') {
    const next = commit(snap.commits.length, [snap.commits[0].sha])
    next.subject = String(action.meta?.message ?? '').split('\n')[0]
    snap.commits = [next, ...snap.commits]
    snap.workingTree = snap.workingTree.filter((f) => !f.staged)
  }
  if (action.kind === 'checkout' && target) {
    snap.repository.currentBranch = target
    snap.branches = snap.branches.map((b) => ({ ...b, isCurrent: b.kind === 'local' && b.name === target }))
  }
}
```

```ts
import { defineStore } from 'pinia'
import type { WireCommit, WireRepositorySnapshot, WireWorkingTreeFile } from '../lib/git-pane/shared/models.ts'
import { GitPaneError, type GitPaneAction, type GitPaneActionKind, type GitPaneService } from '../lib/git-pane/service.ts'
import { toGitPaneError } from '../lib/git-pane/validate.ts'
import { getGitPaneService } from '../lib/git-pane/serviceFactory.ts'

export type { DiffSide } from '../lib/git-pane/service.ts'
export type GitPaneStatus = 'idle' | 'loading' | 'ready' | 'no-repo' | 'no-git' | 'error'

const REFRESH_THROTTLE_MS = 250
const PAGE_SIZE = 200
const NO_REPO_CODES = new Set(['RepositoryNotFound', 'NotARepository'])

let service: GitPaneService | null = null
let unsubscribe: (() => void) | null = null
let refreshTimer: ReturnType<typeof setTimeout> | null = null

function svc(): GitPaneService {
  service ??= getGitPaneService()
  return service
}

interface State {
  status: GitPaneStatus
  repoRoot: string | null
  snapshot: WireRepositorySnapshot | null
  commits: WireCommit[]
  hasMoreCommits: boolean
  selectedSha: string | null
  selectedFiles: WireWorkingTreeFile[]
  included: string[]
  message: string
  amend: boolean
  busyOp: GitPaneActionKind | null
  lastError: GitPaneError | null
}

export const useGitPaneStore = defineStore('gitPane', {
  state: (): State => ({
    status: 'idle', repoRoot: null, snapshot: null, commits: [], hasMoreCommits: false,
    selectedSha: null, selectedFiles: [], included: [], message: '', amend: false,
    busyOp: null, lastError: null,
  }),
  getters: {
    stagedFiles: (s): WireWorkingTreeFile[] => s.snapshot?.workingTree.filter((f) => f.staged) ?? [],
    unstagedFiles: (s): WireWorkingTreeFile[] =>
      s.snapshot?.workingTree.filter((f) => !f.staged && f.status !== 'untracked' && f.status !== 'conflicted') ?? [],
    untrackedFiles: (s): WireWorkingTreeFile[] => s.snapshot?.workingTree.filter((f) => f.status === 'untracked') ?? [],
    conflictedFiles: (s): WireWorkingTreeFile[] => s.snapshot?.workingTree.filter((f) => f.status === 'conflicted') ?? [],
    currentBranch: (s): string => s.snapshot?.repository.currentBranch ?? '',
    aheadBehind: (s): { ahead: number; behind: number } => ({
      ahead: s.snapshot?.repository.ahead ?? 0,
      behind: s.snapshot?.repository.behind ?? 0,
    }),
    canCommit(): boolean {
      const hasContent = this.stagedFiles.length > 0 || this.included.length > 0 || this.amend
      return hasContent && this.message.trim().length > 0 && this.busyOp === null
    },
  },
  actions: {
    bindService(next?: GitPaneService): () => void {
      unsubscribe?.()
      service = next ?? getGitPaneService()
      unsubscribe = service.onChanged(() => this.scheduleRefresh())
      return () => unsubscribe?.()
    },
    scheduleRefresh(): void {
      if (refreshTimer) clearTimeout(refreshTimer)
      refreshTimer = setTimeout(() => { void this.refresh() }, REFRESH_THROTTLE_MS)
    },
    applySnapshot(snap: WireRepositorySnapshot): void {
      this.snapshot = snap
      this.commits = snap.commits
      this.hasMoreCommits = snap.page.hasMore
      this.repoRoot = snap.repository.path
      const paths = new Set(snap.workingTree.map((f) => f.path))
      this.included = this.included.filter((p) => paths.has(p))
      this.status = 'ready'
    },
    async open(folder: string | null): Promise<void> {
      this.$reset()
      if (!folder) return
      this.status = 'loading'
      if (!(await svc().version())) {
        this.status = 'no-git'
        return
      }
      try {
        const res = await svc().open(folder)
        if (res.ok && res.snapshot) return this.applySnapshot(res.snapshot)
        this.status = res.error && NO_REPO_CODES.has(res.error.code) ? 'no-repo' : 'error'
        this.lastError = res.error ? new GitPaneError(res.error.code, res.error.message) : null
      } catch (e) {
        this.status = 'error'
        this.lastError = toGitPaneError(e)
      }
    },
    async refresh(): Promise<void> {
      if (this.status !== 'ready') return
      try {
        this.applySnapshot(await svc().snapshot())
      } catch (e) {
        this.lastError = toGitPaneError(e)
      }
    },
    async loadMoreCommits(): Promise<void> {
      const oldest = this.commits.at(-1)?.sha
      if (!oldest || !this.hasMoreCommits) return
      const res = await svc().commitPage({ beforeSha: oldest, limit: PAGE_SIZE, graphScope: 'all', skip: this.commits.length })
      const known = new Set(this.commits.map((c) => c.sha))
      this.commits = [...this.commits, ...res.commits.filter((c) => !known.has(c.sha))]
      this.hasMoreCommits = res.page.hasMore
    },
    async run(action: GitPaneAction): Promise<boolean> {
      if (this.busyOp) return false
      this.busyOp = action.kind
      this.lastError = null
      try {
        const env = await svc().execute(action)
        if (!env.ok) {
          this.lastError = new GitPaneError(env.error?.code ?? 'unknown', env.error?.message ?? env.message)
          return false
        }
        return true
      } catch (e) {
        this.lastError = toGitPaneError(e)
        return false
      } finally {
        this.busyOp = null
        await this.refresh()
      }
    },
    async stageIncluded(): Promise<boolean> {
      for (const path of this.included) {
        const isAlreadyStaged = this.stagedFiles.some((f) => f.path === path)
        if (!isAlreadyStaged && !(await this.run({ kind: 'stage', target: path }))) return false
      }
      return true
    },
    async commit(opts: { push: boolean; force?: boolean }): Promise<boolean> {
      if (!this.canCommit) return false
      if (!(await this.stageIncluded())) return false
      const kind: GitPaneActionKind = opts.push ? (opts.force ? 'commit-and-force-push' : 'commit-and-push') : (this.amend ? 'amend' : 'commit')
      const ok = await this.run({ kind, meta: { message: this.message.trim(), amend: this.amend } })
      if (ok) {
        this.message = ''
        this.amend = false
        this.included = []
      }
      return ok
    },
    async selectCommit(sha: string | null): Promise<void> {
      this.selectedSha = sha
      this.selectedFiles = sha ? await svc().commitFiles(sha) : []
    },
    toggleIncluded(path: string): void {
      this.included = this.included.includes(path) ? this.included.filter((p) => p !== path) : [...this.included, path]
    },
  },
})
```

```ts
import type { WireWorkingTreeFile } from './shared/models.ts'

export type ChangeGroupId = 'conflicts' | 'staged' | 'changes' | 'unversioned'

export interface ChangeGroup {
  id: ChangeGroupId
  files: WireWorkingTreeFile[]
}

const GROUP_ORDER: ChangeGroupId[] = ['conflicts', 'staged', 'changes', 'unversioned']

function groupOf(file: WireWorkingTreeFile): ChangeGroupId {
  if (file.status === 'conflicted') return 'conflicts'
  if (file.status === 'untracked') return 'unversioned'
  return file.staged ? 'staged' : 'changes'
}

export function groupChanges(files: WireWorkingTreeFile[]): ChangeGroup[] {
  return GROUP_ORDER
    .map((id) => ({ id, files: files.filter((f) => groupOf(f) === id) }))
    .filter((g) => g.files.length > 0)
}
```

```ts
import type { WireBranch, WireTag } from './shared/models.ts'

export interface BranchTreeNode {
  id: string
  label: string
  kind: 'section' | 'folder' | 'branch' | 'tag'
  branch?: WireBranch
  tag?: WireTag
  children: BranchTreeNode[]
}

function insertBranch(root: BranchTreeNode, branch: WireBranch, displayName: string): void {
  const parts = displayName.split('/')
  let parent = root
  for (const folder of parts.slice(0, -1)) {
    const id = `${parent.id}/${folder}`
    let next = parent.children.find((c) => c.id === id)
    if (!next) {
      next = { id, label: folder, kind: 'folder', children: [] }
      parent.children.push(next)
    }
    parent = next
  }
  parent.children.push({ id: branch.id, label: parts.at(-1) ?? displayName, kind: 'branch', branch, children: [] })
}

function section(id: string, label: string): BranchTreeNode {
  return { id, label, kind: 'section', children: [] }
}

export function buildBranchTree(branches: WireBranch[], tags: WireTag[]): BranchTreeNode[] {
  const local = section('local', 'Local')
  const remote = section('remote', 'Remote')
  for (const b of branches) {
    if (b.kind === 'local') insertBranch(local, b, b.name)
    else insertBranch(remote, b, b.name)
  }
  const tagSection = section('tags', 'Tags')
  tagSection.children = tags.map((tag) => ({ id: tag.id, label: tag.name, kind: 'tag' as const, tag, children: [] }))
  return [local, remote, tagSection]
}
```

```ts
import type { DiffSide } from './service.ts'

const SCHEME = 'git-diff://'
const SIDES: DiffSide[] = ['worktree', 'index', 'commit']

export interface DiffTabRef {
  path: string
  side: DiffSide
  sha?: string
}

export function isDiffPath(p?: string): boolean {
  return typeof p === 'string' && p.startsWith(SCHEME)
}

export function encodeDiffPath(ref: DiffTabRef): string {
  const query = new URLSearchParams({ side: ref.side })
  if (ref.sha) query.set('sha', ref.sha)
  return `${SCHEME}${encodeURIComponent(ref.path)}?${query.toString()}`
}

export function decodeDiffPath(uri: string): DiffTabRef | null {
  if (!isDiffPath(uri)) return null
  const [encodedPath, rawQuery = ''] = uri.slice(SCHEME.length).split('?')
  const query = new URLSearchParams(rawQuery)
  const side = query.get('side') as DiffSide | null
  if (!side || !SIDES.includes(side)) return null
  const sha = query.get('sha') ?? undefined
  return sha ? { path: decodeURIComponent(encodedPath), side, sha } : { path: decodeURIComponent(encodedPath), side }
}
```

```vue
<script setup lang="ts">
import { onBeforeUnmount, onMounted, ref } from 'vue';
import { useGitPaneStore } from '../../stores/gitPane';
import { useToastsStore } from '../../stores/toasts';
import { useI18n } from '../../i18n';

const DIRTY_CODES = new Set(['DirtyWorkingTree', 'LocalChangesOverwritten', 'UncommittedChanges']);

const git = useGitPaneStore();
const toasts = useToastsStore();
const { t } = useI18n();
const pending = ref<{ name: string; remote?: string } | null>(null);

async function attempt(name: string, remote?: string, force = false): Promise<void> {
  const meta: Record<string, unknown> = {};
  if (remote) meta.remote = remote;
  if (force) meta.force = true;
  const ok = await git.run({ kind: 'checkout', target: name, meta });
  if (ok) {
    pending.value = null;
    return;
  }
  if (git.lastError && DIRTY_CODES.has(git.lastError.code)) {
    pending.value = { name, remote };
    return;
  }
  if (git.lastError) toasts.error(git.lastError.message);
}

async function stashAndCheckout(): Promise<void> {
  if (!pending.value) return;
  const { name, remote } = pending.value;
  if (await git.run({ kind: 'stash', meta: { message: `SoloMD: before checkout ${name}` } })) await attempt(name, remote);
}

function onCheckout(e: Event): void {
  const detail = (e as CustomEvent<{ name: string; remote?: string }>).detail;
  void attempt(detail.name, detail.remote);
}

onMounted(() => window.addEventListener('gitpane:checkout', onCheckout));
onBeforeUnmount(() => window.removeEventListener('gitpane:checkout', onCheckout));
</script>

<template>

        <span class="spacer" />

        <button class="git-btn" @click="attempt(pending.name, pending.remote, true)">{{ t('git.forceCheckout') }}</button>

</template>
```
