
**Full Description**:
```
SoloMD is a lightweight Markdown + plain text editor designed for focused writing.

FEATURES:
• Live Preview: WYSIWYG-style editing where Markdown syntax hides when you leave the line
• Math & Diagrams: KaTeX for equations, Mermaid for flowcharts
• Multi-Encoding: Auto-detect and preserve GBK, Big5, Shift_JIS (no more garbled text!)
• Export: PDF, DOCX, HTML
• Themes: Light, Dark, and custom CSS
• Clean AI Artifacts: One-click removal of ChatGPT/Claude citation marks and smart quotes
• Cross-Platform: Windows, macOS, Linux
• Tiny Size: Only 15MB installer (vs 250MB for Obsidian)

PHILOSOPHY:
One file. One window. Just write.

Built with Tauri 2 + Vue 3 + CodeMirror 6.

LICENSE: MIT (Free & Open Source)
```
